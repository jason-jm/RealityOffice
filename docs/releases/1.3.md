# Reality Office 1.3

## 中文

Reality Office 在 PICO 头显上提供 Pages 文档、Sheets 表格和 Slides 演示。你可以在空间窗口中编辑文件，以 DOCX、XLSX、PPTX 或 OpenDocument 格式保存，也可以导出 PDF。

- 18 种界面语言统一显示 Reality Office。蓝、橙、绿三色的 R 是新的应用图标。
- 手动保存和自动保存同时发生时会依次写入。保存期间继续输入的内容会保留为待保存，写入失败时保留原件。
- 各窗口分别保存恢复草稿。两个窗口编辑同一个文件时，后保存的窗口会提示磁盘文件已更改。
- Sheets 可以打开使用自定义工作表路径的 XLSX 文件。文件只能部分恢复时会提示保留原件。
- Slides 在首次使用墙面放映时请求空间数据权限。允许后可跟踪墙面，拒绝后可继续浮空放映。

正式版（内部版本号 5）使用 PICO Spatial SDK 6.2.8，适用于 PICO OS 6.2 或以上版本的 arm64 设备。沿用原发布签名，可从 1.2 和 1.3 RC 1 覆盖升级。下载 APK 和 `SHA256SUMS` 后，在同一目录执行下方的校验与安装命令。运行 PICO OS 6.1 的设备可使用[此前的候选版](https://github.com/jason-jm/RealityOffice/releases/tag/v1.3-rc.1)。

## English

Reality Office brings Pages documents, Sheets workbooks and Slides presentations to PICO headsets. Edit files in spatial windows, save in DOCX, XLSX, PPTX or OpenDocument format, and export to PDF.

- All 18 interface languages use the Reality Office name and the new three-colour R icon.
- Manual saves and autosaves run in order. Edits made during a save stay pending, and a failed write preserves the original.
- Each window keeps its own recovery draft. When two windows edit the same file, the next save warns you if the file has changed on disk.
- Sheets opens XLSX workbooks with custom worksheet paths and offers to preserve the original when it can recover only part of a workbook.
- Slides requests spatial data access when you open Present on Wall. Allow access for wall tracking, or decline to keep presenting on a floating panel.

The stable release (build 5) uses PICO Spatial SDK 6.2.8 and requires an arm64 device running PICO OS 6.2 or later. The original signing key supports in-place updates from 1.2 and 1.3 RC 1. The [release candidate](https://github.com/jason-jm/RealityOffice/releases/tag/v1.3-rc.1) remains available for PICO OS 6.1. Download the APK and `SHA256SUMS` into the same directory, then run the following commands.

```sh
shasum -a 256 -c SHA256SUMS
adb install -r RealityOffice-v1.3.apk
```
