# Reality Office 1.3.3

## 中文

- 在任一编辑器的「文件 → 打开」中选择文档、工作簿或演示文稿，会在当前窗口交给对应的编辑器。固定文件也使用相同流程。当前编辑器有未保存的修改时，可以保存、放弃或取消切换。
- Pages 的「比较文档」现在将文件列表显示在前台，只列出可以作为修订稿读取的文件。选择或取消后保留比较设置。Slides 的「重用幻灯片」只列出演示文稿，并支持选择 `.ppsm` 放映文件。

内部版本号为 8，使用 PICO Spatial SDK 6.2.8。支持运行 PICO OS 6.2 或更高版本的 arm64 设备，可从 1.3.2 覆盖升级。

## English

- File → Open now opens documents, workbooks and presentations in the matching editor in the current window. Pinned files use the same behavior. When the current document has unsaved edits, you can save them, discard them or cancel the switch.
- Compare Documents in Pages brings the file browser to the foreground and lists files the document reader accepts. Your comparison settings survive selecting a file or cancelling. Reuse Slides lists presentations and includes `.ppsm` slide shows.

Build 8 uses PICO Spatial SDK 6.2.8 and runs on arm64 devices with PICO OS 6.2 or later. Download the APK and checksum file into the same directory to verify and install the update.

```sh
shasum -a 256 -c SHA256SUMS
adb install -r RealityOffice-v1.3.3.apk
```
