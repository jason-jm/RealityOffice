# Reality Office 1.3.2

## 中文

- 在系统文件选择器中可以选择 Markdown、HTML、RTF 和 OpenDocument 模板，以及编辑器支持的 Office 模板、放映文件和 WPS 格式。
- 从其他应用分享 ODS、ODT、ODP 等文档时，可以选择 Reality Office。系统通过附件 URI 或剪贴数据传递文件时，应用会将文件导入相应的编辑器。
- 分享一段文字时，Reality Office 会把文字保存为本地文档。同名分享会各自保留副本。

版本 1.3.2（内部版本号 7）使用 PICO Spatial SDK 6.2.8，适用于运行 PICO OS 6.2 或更高版本的 arm64 设备。已安装 1.3.1 的用户可以覆盖升级。

## English

- The system file picker now accepts Markdown, HTML, RTF, OpenDocument templates and the Office templates, slide shows and WPS formats supported by the editors.
- Share documents such as ODS, ODT and ODP from other apps directly to Reality Office. The app accepts attachments delivered through the standard Android stream or clipboard-data fields.
- Sharing text creates a local document. Repeated shares with the same name keep individual copies.

Build 7 uses PICO Spatial SDK 6.2.8 and requires an arm64 device running PICO OS 6.2 or later. Download the APK and checksum file into the same directory to verify the download and update your headset.

```sh
shasum -a 256 -c SHA256SUMS
adb install -r RealityOffice-v1.3.2.apk
```
