# Reality Office 1.3.4 · Build 10

## English

Reality Office now uses the Android package `com.therealityteam.realityoffice`. This signed APK is the build prepared for the PICO consumer and enterprise stores. It runs on PICO Space Pro with PICO OS 6.2 or later and uses PICO Spatial SDK 6.2.8.

If you already use build 9 or an earlier release, both versions can be installed on the same headset. To bring over a draft, open it in the old app, choose **File → Save a Copy to…**, and save it in a shared folder such as Download. Choose **Open from device or cloud…** in the new app to open the copy. Each installation keeps its own recent files, preferences and permissions.

## 简体中文

Reality Office 的 Android 包名已改为 `com.therealityteam.realityoffice`。GitHub 下载与 PICO 消费者商店、企业商店送审使用同一份正式签名 APK。本构建使用 PICO Spatial SDK 6.2.8，适用于运行 PICO OS 6.2 或更高版本的 PICO Space Pro。

已安装构建 9 或更早版本的头显可以同时保留两个版本。要把草稿带到新版，先在旧版打开草稿，选择「文件 → 保存副本到…」，将副本存入 Download 等共享文件夹，再在新版点击「从设备或云端打开…」。两个版本各自保存最近文件记录、设置和应用权限。

```sh
shasum -a 256 -c SHA256SUMS
adb install -r RealityOffice-v1.3.4-build10.apk
```
