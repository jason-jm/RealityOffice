# Reality Office 1.3.1

## 中文

- 主页会随窗口宽度调整文件搜索、类型筛选和最近文件列表。在窄窗口中，文件位置和打开时间显示在名称下方，模板可以横向滚动。
- 连续打开多个文档时，每个文件会分配到可用窗口。四个窗口都在编辑时，应用会提示先腾出一个窗口，保留当前编辑内容。
- 另存为时保留文件名中的版本号（例如 `预算.v2.ods`）及当前可写格式。如果磁盘上的文件已改变，选择另存后会继续此前的关闭操作。
- PDF 导出或文件导入中断时保留原件。同时导入的同名文件会各自保存。不同窗口通过系统选择器保存副本时，结果会交回各自的编辑器。

版本 1.3.1（内部版本号 6）使用 PICO Spatial SDK 6.2.8，适用于运行 PICO OS 6.2 或更高版本的 arm64 设备。已安装 1.3 的用户可以直接覆盖升级。

## English

- The home screen adapts search, file filters and the recent list to the width of the window. In narrow windows, the folder and last-opened time appear under the file name, and the template gallery scrolls horizontally.
- Opening several documents in succession assigns each one to an available window. When all four editors are occupied, Reality Office preserves your edits and asks you to free a window.
- Save As preserves version numbers in names such as `Budget.v2.ods` and defaults to the document’s current writable format. Choosing Save As after a conflict also completes the pending close.
- Interrupted PDF exports preserve the previous PDF. Interrupted imports leave no partial document, and simultaneous imports with the same name each keep their own copy. System picker results return to the editor that requested each copy.

Build 6 uses PICO Spatial SDK 6.2.8 and requires an arm64 device running PICO OS 6.2 or later. Download the APK and checksum file into the same directory to verify the download and update an existing installation.

```sh
shasum -a 256 -c SHA256SUMS
adb install -r RealityOffice-v1.3.1.apk
```
