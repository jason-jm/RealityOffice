# Reality Office 1.3.4

## 中文

在 Slides 的「幻灯片放映 → 投影到墙面」中拒绝空间数据权限后，演讲者窗口现在会提示幻灯片正在前方浮空放映。你仍可翻页和结束放映。允许权限后，演讲者窗口会说明幻灯片可自动贴合检测到的墙面。此修复覆盖全部 18 种界面语言。

内部版本号为 9。使用 PICO Spatial SDK 6.2.8，支持运行 PICO OS 6.2 或更高版本的 arm64 设备，可从 1.3.3 覆盖升级。

## English

When you choose **Slide Show → Present on Wall** and decline spatial data access, the presenter console now tells you that the slides are floating in front of you. You can still advance slides and end the show. If you grant access, the console explains that the slides can attach to a detected wall. The update covers all 18 interface languages.

Build 9 uses PICO Spatial SDK 6.2.8. It supports arm64 devices running PICO OS 6.2 or later. Download the APK and checksum file into the same directory to verify and install the update.

```sh
shasum -a 256 -c SHA256SUMS
adb install -r RealityOffice-v1.3.4.apk
```
