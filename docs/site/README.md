# Website media

The Reality Office interface shown on the website comes from the PICO OS 6.2 emulator. The opening artwork arranges the actual Set list document and Soundcheck slide windows in a captured room. The three editor illustrations use details from real files. The spatial windows photograph is a single emulator capture with both windows in their native positions.

The English product film runs for 32.5 seconds. It pairs footage of the editors with the original electronic track *Double Tap*, produced with Suno for the film. English captions are available in the player.
