# A weekend by the sea

Plan a two-day trip with an itinerary in Pages, a travel budget in Sheets and a three-slide story in Slides. Each pack contains the same trip in the language you choose. [English files (ZIP)](https://raw.githubusercontent.com/jason-jm/RealityOffice/main/examples/coast-weekend/coast-weekend-en.zip) · [中文文件（ZIP）](https://raw.githubusercontent.com/jason-jm/RealityOffice/main/examples/coast-weekend/coast-weekend-zh-CN.zip)

In the budget, change the first day’s food expense in C8 from 76 yuan to 90. The remaining balance changes from 119 to 105. The Reality Team created the sample files under the project’s [MIT license](../../LICENSE).

For the files in the current product screenshots, see [Saturday Print Club](../print-club/).
